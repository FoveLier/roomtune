# RoomTune 设计说明（DESIGN）

**Status: approved**

## 1. 设计原则

- **工具感，不是装饰品**：浅灰工作台、白卡片、清晰分组、足够留白；不使用渐变、玻璃拟态、循环动效。
- **一眼看出下一步**：每个页面只承担一个主任务；主按钮只有一个。
- **先数据后结论**：数值、风险、参数卡先出现；解释文字辅助，不用大段“AI 文案”占屏。
- **双端一致**：PC 与手机使用同一套颜色、字体层级、卡片/标签语义；PC 适合宽屏编辑，手机适合单手查看。
- **克制使用颜色**：蓝色只表示可操作/当前；红/橙/绿只表示风险级别。

### Spacing / Radius

- PC：8px 基准栅格；页面 padding 24–26px；卡片 padding 18px；卡片间距 14px；圆角 8px。
- 手机：8rpx 基准；页面 padding 24rpx；卡片 padding 24rpx；圆角 16rpx。
- 输入/按钮高度：PC 30–34px；手机 76–80rpx。

### Motion

- 无循环动画、无页面级过场。
- 仅使用 WPF/uni-app 默认的即时 hover/pressed 反馈；不做 AI 式渐变呼吸。

## 3. 双端布局

### PC

```text
┌──────────────┬──────────────────────────────────────────────┐
│ RoomTune     │ 页面标题 / 一句说明                           │
│ 声居 · 校正  │                                              │
│              │ ┌──────────────┐ ┌─────────────────────────┐ │
│ 项目         │ │ 表单/数据卡   │ │ 平面图/图表/报告          │ │
│ 房间与系统   │ │              │ │                         │ │
│ 声学分析     │ └──────────────┘ └─────────────────────────┘ │
│ 校正方案     │                                              │
│ 测量         │                                              │
│ 报告         │                                              │
│ 设置         │                                              │
│ [同步码]     │                                              │
│ F:\RoomTuneData                                             │
└──────────────┴──────────────────────────────────────────────┘
```

- 左侧栏固定 220px；白底 1px 分隔；当前项浅蓝底/蓝字。
- 主内容可滚动；页面标题 26px；说明 12px。
- 表单使用“字段名 + 输入”两列/三列；输入高度一致；不堆说明文字。
- 平面图为白底浅网格，蓝点音箱/橙方低音炮/青点听音位/× 第一反射点。
- 图表无外框装饰，直接放在白卡片内；网格线极浅。

### 手机

```text
状态栏
导航栏（原生/白底）
页面标题 + 一句说明
卡片：新建/项目列表
卡片：房间/系统字段
按钮：保存并分析
底部 tab：项目 / 同步 / 设置
```

- 404 宽度下 24rpx 边距；每条项目卡显示名称、尺寸/布局、更新时间。
- 房间页字段分组为“房间”“音箱与动态范围”；picker 只显示当前值。
- 分析页 2×2 汇总卡 + 模态 CSS 柱状图 + 风险卡。
- 方案页方案卡按分数排列；参数卡使用等宽字体，可复制。

| 组件 | 规格 |
| --- | --- |
| Page title | PC 26px/手机 48rpx；左侧对齐；不带多余 eyebrow |
| Card | 白底、1px #DCE2EA、8px/16rpx 圆角、18px/24rpx padding |
| Label | 12px/22rpx 灰；与输入垂直居中 |
| Input/Picker | 1px 边框；聚焦蓝边；手机占满剩余宽度 |
| Primary button | 蓝底白字；PC padding 14/7；手机 80rpx 高 |

| Scheme card | 标题+分数+摘要+优点/取舍+步骤；不用阴影堆叠 |
| Parameter card | 等宽字体，自动换行，首行分频，末行置信度 |
| Sync code | 长文本框；生成/复制/粘贴/导入；代码内容不自动上传 |
| Empty state | 一句话说明 + 一个可执行按钮 |

## 5. 页面状态

- **空项目**：手机项目页显示“还没有项目”；PC 自动创建默认项目避免空白。
- **无测量**：测量页显示空图表和“导入 REW CSV”提示；分析/报告/参数卡显示“估算”。
- **加载/失败**：PC 用同步 IO + MessageBox/状态文本；手机用 toast/modal。无全屏 loading 遮罩。
- **长列表**：模态/风险/方案都在滚动容器内，不隐藏滚动条。
- **高风险**：风险卡左侧使用高/中/低徽标；不改变整页颜色。

## 6. 无障碍与可用性

- PC 可键盘 Tab 进入输入/按钮；按钮文字使用动词（保存、导入、应用、复制）。
- 手机触控区域 ≥ 76rpx；按钮不换行、不截断。
- 颜色对比：主文字 #1F2937 于 #FFFFFF；风险色只作辅助，文字本身说明含义。
- 所有数值输入都带单位（m、Hz、dB、%）。
- 参数卡明确“估算/含实测参考”，避免把计算值伪装成测量结果。

## 7. 不做的设计

- 不做暗色炫技主题、动态渐变背景、循环粒子/唱片动效。
- 不做无意义英文 eyebrow、图标墙、重复标题+副标题+说明+标签。
- 不复制 Dirac/Audyssey/网易云等品牌资产。
- 不为“看起来 AI”而增加装饰；界面服务于房间诊断。
