# RoomTune · 4–6 分钟演示录屏脚本（由本人录制）

> 目标：完整操作演示 + 特色说明。建议 1080p，麦克风/系统声音均可；不要只放静态 PPT。

## 0:00–0:20 开场

- 画面：PC 端项目页；同时露出 GitHub 仓库页或 README。
- 口述：项目名、解决的问题（先摆位/声装/测量，再 EQ）、PC + 手机双端、数据只存本机。

## 0:20–1:20 PC 项目与房间

- 新建项目“客厅影院”；输入 5.4 × 3.8 × 2.7 m。
- 选木地板、乳胶漆墙面、石膏板吊顶、窗占比 20%、家具中等。
- 选择 2.1 / 5.1.2，输入音箱型号、低频 45 Hz、灵敏度 87 dB、最大声压 105 dB、动态范围 95 dB。
- 在 2D 平面图上拖动左/右主箱、低音炮和听音位；说明反射点与离墙距离。
- 点击“保存并更新分析”，说明写入 `F:\RoomTuneData`。

## 1:20–2:10 声学分析

- 展示体积、RT60 区间、Schroeder、动态余量、模态数量、置信度。
- 模态图/列表：解释轴向/切向/斜向。
- 风险：混响偏长、低频模态聚集、第一反射点、动态余量。
- SBIR/第一反射列表；强调“估算/实测”标签。

## 2:10–3:00 校正方案

- 三个方案：现状微调 / 对称等边摆位 / 摆位+声装；说明分数/取舍。
- 点击“应用对称摆位”，回分析页看变化。
- 装修清单：低频陷阱、第一反射吸音、软装、扩散；说明预算与优先级。
- 参数卡：分频、距离、延迟、相位、PEQ 候选；强调不是实时 DSP，需要 REW 复核。

## 3:00–3:50 测量与报告

- 测量页导入 `docs/sample-measurement.csv`（演示用示例）；展示对数频率曲线、点数、来源。
- 报告页展示 Markdown 报告；导出 Markdown/HTML 到 `F:\RoomTuneData\exports`。
- 设置页展示 AI Key 输入位置；说明没有 Key 时本地报告仍可用，AI 只解释已算数据。

## 3:50–4:50 手机端与同步

- 手机端（APK/H5）项目页、房间页、分析页、方案页。
- 生成手机同步码；PC 同步码窗口粘贴 → 导入为新项目（或反向）。
- 说明双端字段一致、导入生成新 ID、不覆盖。

## 4:50–5:30 特色与边界

- 特色：先免费摆位/软装，再声装，最后 EQ；确定性规则 + 可解释报告；双端同步；数据本地。
- 边界：不替代 Dirac/Audyssey，不做实时 DSP；精确参数需 UMIK-1 + REW。
- 展示 GitHub 仓库、docs/spec、review、AI 披露；说明录屏与代码由本人完成。
