# RoomTune 规格说明（Spec）

**Status: approved**

## 1. 目标与边界

RoomTune 是一套面向家庭影院/HiFi 入门用户的数字房间声学校正决策系统。它把用户真实的房间尺寸、材质、音箱/听音位和 REW 测量转成可执行建议：先摆位，再软装/声装，最后才做 EQ/校准参数。

**双端定位：**

- **PC 端**：Visual Studio 2022 + WPF + .NET Framework 4.8 桌面应用，独立运行，负责完整编辑、2D 拖拽、REW CSV 导入、报告导出、AI 解释和同步码。
- **手机端**：HBuilderX + uni-app Vue3 Android App，独立完成项目、房间录入、分析、方案和参数卡；与 PC 通过 Base64 JSON 同步码交换项目。

**不做：** 微信小程序版本、web-view、支付、手机号验证、实时音频 DSP、直接控制 AVR/Dirac/ Audyssey、云同步。精确参数由用户现有设备/软件执行，并以 UMIK-1 + REW 实测复核。

## 2. 用户故事

1. 作为家庭影院用户，我想录入房间尺寸、材质和音箱数量，看到低频模态/混响风险。
2. 作为 HiFi 用户，我想拖动主箱/低音炮/听音位，看到距离、角度、第一反射点与 SBIR 风险。
3. 作为没有测量经验的人，我想先得到零成本摆位方案，再决定软装/装修预算。
4. 作为进阶用户，我想导入 REW 导出的 CSV，看到实测频响并把“估算”升级为“含实测参考”。
5. 作为普通用户，我想看到“先做什么、为什么、风险是什么”的中文报告，而不是一堆参数。
6. 作为用户，我想把项目从 PC 带到手机继续看/修改，或反向带回 PC。
7. 作为用户，我不想上传个人房间数据；所有项目数据应只留在本机。

## 3. 功能需求

### 3.1 PC 项目页

- 列出 `F:\RoomTuneData\projects\*.json`；新建、打开、删除、导入同步码。
- 新建项目默认生成一个 2.1 示例房间，可立即编辑。
- 显示数据目录和同步方式。
- 删除需二次确认；删除最后一个项目后自动重建默认项目，避免空状态。

### 3.2 PC 房间与系统页

- 编辑项目名、长/宽/高、形状、地面/墙面/吊顶材质、窗占比、家具量、听音位 X/Y。
- 编辑布局（2.0/2.1/5.1/5.1.2/7.1.4）、型号、低音炮数、低频/高频、灵敏度、最大声压、动态范围、听音音量、目标用途/曲线。
- 2D 平面图：拖动主箱、低音炮、听音位；显示房间网格、反射点、相对位置。
- 保存后写 `F:\RoomTuneData\projects\<id>.json`，刷新分析；布局或低音炮数量变化时按新布局重生成音箱位置。
- “应用对称摆位”生成 64% 长度、左右对称、主箱前移的基线；“重置布局”按当前布局重建。

### 3.3 PC 声学分析页

- 汇总：体积、RT60 区间、Schroeder 频率、动态余量、模态数量、置信度。
- 模态分布图（16–300 Hz）和模态列表；轴向/切向/斜向分色。
- 风险列表：RT60 偏长/偏干、比例狭长、低频模态聚集、音箱贴边界、左右不对称、第一反射、动态余量不足、非矩形近似、无实测。
- SBIR 候选：前墙/侧墙/地面/天花距离与 `c/(4d)` 估算频率。
- 第一反射点：侧墙镜面点与路径长度。

### 3.4 PC 校正方案页

- 三个摆位方案：现状微调、对称等边摆位、摆位+声装；显示分数、优点、取舍、步骤。
- 声学装修清单：优先级、位置、面积、厚度、频段、预算、效果、注意事项。
- 校准参数卡：分频、距离、延迟、低音炮相位/延迟建议、目标曲线、EQ headroom、PEQ 候选、置信度。
- 保存方案快照；复制参数卡；导出同步码。

### 3.5 PC 测量页

- 用 OpenFileDialog 选择 REW CSV；解析每行前两个数字（频率/ dB），支持逗号/分号/制表符/空格分隔。
- 画对数频率轴频响曲线；显示来源、导入时间、点数、频率范围。
- 无测量时明确显示“估算”；导入后报告/参数卡置信度变为“含 REW 测量参考”。
- 清除测量需确认。

### 3.6 PC 报告/设置

- 报告：确定性 Markdown 报告，包含房间、关键结果、风险、方案、装修、参数卡、下一步。
- 导出 Markdown/HTML 到 `F:\RoomTuneData\exports`；复制报告。
- 可选 AI：OpenAI-compatible API；用户自填 Base URL/model/Key；Key 存 `F:\RoomTuneData\config.json`；无 Key 时本地报告可用；AI 只解释已算数据。
- 设置：AI 配置、数据目录、打开数据目录。

### 3.7 PC ↔ 手机同步码

- 编码：`Base64(UTF8(JSON(Project)))`；只包含项目数据，不含 AI Key/config。
- PC 同步码窗口：复制、从剪贴板粘贴、导入为新项目。
- 手机同步页：生成当前项目码、复制、粘贴、导入为新项目（项目名追加“（同步）”）。
- PC 与手机的项目 JSON 字段一致（PascalCase）；日期为字符串；测量点可随项目同步。
- 导入必须生成新 ID，绝不覆盖现有项目。

### 3.8 手机端页面

- **项目**：项目列表、新建、打开、删除；本地 Storage 保存；底部 tab：项目/同步/设置。
- **房间与系统**：与 PC 相同的核心字段；材质/形状/布局/目标用 picker；Canvas 显示房间和音箱相对位置；保存并分析。
- **声学分析**：体积/RT60/Schroeder/动态余量；CSS 模态柱状图；风险、SBIR、第一反射、置信度；跳转方案。
- **校正方案**：三个方案、装修清单、参数卡文本；应用对称摆位、保存方案、复制参数卡、去同步。
- **同步码**：生成/复制/粘贴/导入。
- **设置**：存储、项目数、版本、清空全部项目；说明 PC 数据目录。
- 手机端不调用网络；无账号/后端。

## 4. 数据与算法

### 4.1 项目模型（关键字段）

```text
RoomProject {
  Id, Name, Notes, CreatedAt, UpdatedAt,
  Room { LengthM, WidthM, HeightM, Shape,
         FloorMaterial, WallMaterial, CeilingMaterial,
         WindowRatioPercent, FurnitureLevel, ListenerX, ListenerY },
  System { Layout, SpeakerCount, SubwooferCount, SpeakerModel,
           LowFreqHz, HighFreqHz, SensitivityDb, MaxSplDb,
           DynamicRangeDb, ListeningLevelDb, TargetUse, TargetCurve,
           Speakers [{ Role, X, Y, Angle, HeightM, IsSubwoofer }] },
  Measurement { Source, ImportedAt, Points [{ FrequencyHz, SplDb }] },
  SavedSchemes [...]
}
```

### 4.2 确定性计算

- 声速 `c = 343 m/s`。
- 矩形模态：`f = (c/2) * sqrt((nx/L)^2 + (ny/W)^2 + (nz/H)^2)`，排除 (0,0,0)，16–300 Hz，按 1 Hz 去重。
- 平均吸声：地面/吊顶面积 `L*W`，墙面 `2*(L*H+W*H)`；窗占比把墙面部分替换为玻璃；家具吸收 1.5/4/7 m²。
- Sabine：`RT60 = 0.161 * V / A`，展示 ±18% 区间，钳制 0.15–1.8 s。
- Schroeder：`fs = 2000 * sqrt(RT60 / V)`。
- SBIR：边界距离 d 的抵消估算 `f = c/(4d)`（20–300 Hz），`d < 0.45m` 为高，`0.45–1.0m` 为中。
- 第一反射：侧墙镜像法求反射点与路径长度。
- 动态余量：`MaxSplDb - ListeningLevelDb`；建议最大提升 `clamp(headroom-6, 0, 6)`。
- 方案分数：从 100 扣 RT60 偏长/偏干、SBIR、左右不对称、模态聚集、headroom 不足，钳制 35–98。
- 装修优先级：低频陷阱 → 第一反射吸音 → 软装 → 后墙扩散；以目标 RT60 0.32/0.40 s 及当前吸声差估算面积。
- 参数卡：分频 `clamp(max(80, 1.5*LowFreq), 40, 120)`，取 5 Hz 整；距离/延迟按扬声器到听音位；PEQ 只给 40–200 Hz 的 -3 dB Q=8 切峰候选，明确“先实测”。

### 4.3 推荐规则（硬约束）

- 先免费摆位/软装，后硬装，最后 EQ。
- 不把深谷的 boost 当作解决方案；深谷优先摆位/声装。
- 没有测量时，参数卡必须标注“估算起点”。
- 不虚构测量点、目标曲线或品牌结论。
- 不在报告中输出个人密钥/配置。

## 5. 状态与错误

- 数据目录不存在：自动创建；无法写入时显示错误，不静默丢数据。
- JSON 损坏：跳过并在 `logs/roomtune.log` 记录；不覆盖原文件。
- CSV 无有效数据行：拒绝导入并提示“需要频率, dB 两列”。
- 同步码无效：提示错误，不导入。
- AI 未配置/失败：保留本地报告，提示配置或重试；不阻塞页面。
- 无测量：分析/报告显示估算；无风险为空时显示明确空状态。
- PC 窗口关闭：所有已保存项目持久化；未保存的表单改动不写盘（保存按钮语义明确）。

## 7. 测试策略

- PC Core：控制台断言测试（模态、RT60、SBIR、摆位、同步、CSV、推荐、参数卡）。
- PC UI：实际启动并逐页截图；拖动/保存/导入/同步码操作验证。
- 手机：Node 纯函数测试 + HBuilderX H5 实际运行逐页检查；最后 APK 安装/启动检查（若设备/模拟器可用）。
- 交叉同步：PC 编码 → 手机解码；手机编码 → PC 解码。
- 失败路径：无效 CSV、空同步码、AI 未配置、无效项目 JSON。
